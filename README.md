# Stroomtip — scherm

Deze repo bevat alleen de uitkomst: een pagina die laat zien wanneer het
vandaag het gunstigst is om de vaatwasser en de was te draaien, plus de
kwartierprijzen van de dag.

Openbaar omdat GitHub Pages dat op een gratis account vereist. Er staat niets
dat naar een persoon of adres te herleiden is: geen naam, geen adres, geen
sleutels. De locatie is bewust grof (afgerond op één decimaal, ruwweg tien
kilometer), alleen voor de weersverwachting. Verder staan er stroomprijzen,
tijdvensters en de instellingen van de zonnepanelen en apparaten in.

De berekening en de exacte instellingen zitten in een aparte, privérepo.
